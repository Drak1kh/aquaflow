# AquaFlow Design

## Color palette

Use this palette consistently across the water management application. Keep dark blues for text, navigation, and strong actions; reserve the lighter blues for supporting accents and backgrounds.

| Name | Hex | Use |
|---|---|---|
| Deep Ocean | `#063E91` | Primary dark surfaces, headings, and sidebar backgrounds |
| Ocean Blue | `#0869CF` | Primary brand color and button backgrounds |
| Aqua Blue | `#079EE9` | Links, active states, and charts |
| Flow Cyan | `#12C4EE` | Highlights, gradients, and indicators |
| Light Aqua | `#5BD5F2` | Secondary accents and hover states |
| Mist Blue | `#BDECF8` | Light backgrounds and informational cards |
| Water White | `#F7FCFE` | Main application background |
| Deep Navy | `#062E68` | Body text, navigation labels, and high contrast content |

## Usage guidance

- Use Water White for the main canvas, with Deep Navy for readable text.
- Use Ocean Blue for primary actions and Aqua Blue for interactive links and selected states.
- Use Deep Ocean for dark navigation surfaces; maintain clear contrast for labels and controls.
- Use Flow Cyan and Light Aqua as accents. Use Mist Blue for supporting surfaces rather than dense text.
- Check text and control contrast against the final background, especially when using the lighter colors.
- Keep charts understandable without relying on color alone; pair color with labels, shapes, or patterns.
